# 九图叙述框架

这是可调整的叙述顺序，不是每个商品都必须制作九张。先按用户的张数、品类、事实和卖点安排；不要把雨伞样图的数据搬到其他商品。

| 图位 | 读者的问题 | 可用画面 |
|---|---|---|
| 01首图 | 这是什么，有什么主要吸引点？ | 清晰完整的主商品、积木舞台、少量角色和像素符号 |
| 02规格 | 多大、多重，收纳后怎样？ | 已核对尺寸的测距线、端点、单位、双状态展示 |
| 03材质/功能 | 它的材料或关键功能是什么？ | 真实表面、内层或材料细节，箭头指向实际部位 |
| 04场景 | 会在什么时候用到？ | 3D积木人物、建筑和环境围绕写实商品 |
| 05结构 | 内部或支撑结构怎样？ | 依据真实细节精修，不编造零件或测试结论 |
| 06工艺 | 缝线、边缘、接头等做工怎样？ | 一大两小或其他平衡的细节拼图 |
| 07操作/收纳 | 怎么开合、整理或带走？ | 当前商品真实操作、折叠、束带或收纳状态 |
| 08接触/握持 | 接触手部的部件、带子或握把怎样？ | 准确表面、完整连接、真实开口和带子 |
| 09选择 | 有哪些颜色或规格？ | 与当前SKU映射一致的并列选择 |

## 执行要点

- 一张讲一个主要信息；全景、细节、场景、状态之间有节奏。
- 规格和单位来自本次商品资料；测距线应真实对应测量方向，不只是悬空文字。
- 同一个商品的不同材料分别保留，例如光滑刚性表面与编织软带；不把所有部件抹成同一种材质。
- 几何检查包含整体透视和局部连接，不能只证明一条拟合线经过一个点。
- 各颜色套图改变元素动作、底座轮廓、整体摆位及渐变位置；同时保持标题样式和主次一致。
- 当某图不适合当前品类时替换或删除，不编造卖点来凑九张。
