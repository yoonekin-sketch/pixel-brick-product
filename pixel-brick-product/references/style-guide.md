# 风格规范

## 视觉层次

| 层级 | 表现 |
|---|---|
| 主商品 | 写实摄影、真实外形和材质，不像素化或积木化 |
| 装饰与场景 | 立体体素积木，倒角、接缝、凸点、软阴影清楚 |
| 文案 | 可读泰文、深蓝粗体与浅青字影；标注简单直接 |
| 背景 | 以白为主，轻微低饱和局部渐变、淡灰接地影 |

迷你积木伞可以有玩具弯钩柄；真实伞柄仍由实拍决定。人物、猫狗、建筑使用同一立体积木材质与光源。

## 排版与标题

- 先认出商品，再读卖点。雨伞首图通常露出中杆、真实短柄和腕带；圆伞面正视图可用于SKU双状态展示，不自动代替首图。
- 1254方图参考安全区：左上约x60—300、y60—190给Logo，右上同宽。按实际标题和Logo协调，不画占位框。
- 主标题相对整幅画布居中。泰文字形圆润厚实，声调完整；像素感由轻微阶梯字影和环境提供，不把泰文拆成不可读的方块。
- 同套锁定字形、视觉高度和字影。长标题在共同安全宽度内排一行；必要时按本次文案授权提出短标题，不压扁文字或只把某张做得特别小。
- 留白服务主次。失衡空区可补少量迷你积木伞、花、小块、雨滴或像素符号，不填满所有空白。
- 产品标签通常独立排版；除非用户明确设计实体标牌，不直接印在装饰积木上。

## 配色与舞台

- 深蓝标题，湖蓝主积木，青柠/珊瑚/薄荷/奶油/浅紫点缀；不要高饱和满屏彩虹。
- 背景仍看着是白色。改变一到两个极淡光晕的位置、方向、范围和冷暖，不整套照搬同一个蓝渐变。
- 底座可为像素云、阶梯、弧形分岛、不对称平台。露出的凸点与错落轮廓共同表达积木。
- 圆凸点或圆角方凸点均可，形体、间距、透视应可信。承托区可平，但前缘和两翼必须有明显凸点。

## 系列变化

| 项目 | 方法 |
|---|---|
| 商品摆位 | 完整商品平移、转向、竖放、平放、轻斜；精密部件不单独旋转 |
| 底座 | 像素云、弧形、阶梯、分岛、高低平台 |
| 角色 | 男女公仔与猫狗交叉；熟睡、伸懒腰、迈步、挥手、拍手、跳水洼 |
| 小物 | 小积木伞、花、散落块、雨滴、闪光、像素箭头 |
| 背景 | 极淡渐变的位置、方向与冷暖 |
| 镜头节奏 | 全景、双状态规格、内层、场景、结构、工艺拼图、收纳、握把、选色 |

跨颜色系列的同一卖点，至少改变一项主要构图或角色动作，配合背景变化，不能只换商品颜色。结构复杂时允许保留稳定视角，把变化交给舞台和角色。

## 精修

材质修正要保持轮廓、开口、轴线、相邻零件与文字不动。放大比较修改区域和邻近连接，不能只看整张缩略图就宣布问题解决。
